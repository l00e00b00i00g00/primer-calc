# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/l00e00b00i00g00/primer-calc/security/advisories/new)
— please do not open public issues for security reports.

Include: affected versions, a minimal reproduction (primer sequence +
conditions), and the observed vs expected behavior. We aim to acknowledge
within 72 hours and to ship a fix with a patch release plus a `SECURITY`
note in `CHANGELOG.md`.
